Free AI API key 免费申请 API Key

Don’t want to pay for AI yet? A free API key is often enough for light use. Paste it in the app under Settings → AI. 暂时不想为 AI 花钱？在够用的前提下，可以先申请免费 API Key，粘贴到 App 的设置 → AI。

Note: ChatGPT / Gemini app memberships are not API keys. 提示：ChatGPT / Gemini 的聊天会员不能当 API Key 用。

Easiest start — Google sign-in. Free limits vary; check the console. 最省事：Google 登录即可。免费额度以控制台为准。

1

Open Google AI Studio 打开 Google AI Studio

Sign in with Google (phone or desktop browser). 用 Google 账号登录（手机或电脑浏览器均可）。

Open AI Studio 打开 AI Studio
2

Create an API key 创建 API Key

Tap Get API key / Create API key. 点 Get API key / Create API key。

3

Copy the key 复制密钥

Keep it private — don’t share it publicly. 请私密保存，不要公开分享。

4

Paste into the app 粘贴到 App

Settings → AI → choose Google / Gemini → paste → Save. 设置 → AI → 选择 Google / Gemini → 粘贴 → 保存。

One key, many models. Free models have daily limits (often ~50/day). 一把 Key 可用多种模型。免费模型有日限额（常见约 50 次/天）。

1

Sign up on OpenRouter 注册 OpenRouter

Google or GitHub login. Free models don’t require credits. Google 或 GitHub 登录。只用免费模型时不必充值。

Open OpenRouter 打开 OpenRouter
2

Create an API key 创建 API Key

Keys → Create. Name it anything you like. Keys → Create。名称随意。

3

Pick a free model 选用免费模型

Prefer model ids ending in :free for $0 token cost. 优先选模型 ID 带 :free 的，token 费用为 $0。

4

Paste into the app 粘贴到 App

Settings → AI → OpenRouter → paste key → Save. 设置 → AI → OpenRouter → 粘贴 Key → 保存。

Your key stays on the device. AI text is sent only to the provider you choose. Free quotas change — check their console. Key 保存在本机。整理内容只会发到你选择的服务商。免费额度会变，请以对方控制台为准。
